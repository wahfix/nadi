## CARA AGENT MENGGUNAKAN SUITE INSTRUKSI INI
1. Setiap kali akan mengerjakan atau memverifikasi fitur tertentu, baca terlebih dahulu modul instruksi terkait.
2. Patuhi hierarki prinsip tertinggi: `INTEGRITAS DATA > KEBENARAN FINANSIAL > KEAMANAN > AUDITABILITAS > UX > VISUAL POLISH`.
3. Setelah setiap fase pembangunan, wajib jalankan checklist di [`12_BUILD_STRATEGY_AND_QUALITY_CHECKLIST.md`](./12_BUILD_STRATEGY_AND_QUALITY_CHECKLIST.md) dan pastikan tidak ada error tersisa.
